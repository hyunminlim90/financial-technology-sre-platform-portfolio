# 이진 실행 파일 (Binary Executable File)

> 정독: 0회

## 1. 이 기술이 무엇인가

이진 실행 파일(Binary Executable File)은:

> 컴파일 과정을 거쳐 생성된 실행 가능한 기계어 코드의 정적 저장 형태

**입력:** 소스 프로그램  

**출력:** 실행 파일

CPU는 소스 코드를 직접 실행하지 못합니다. CPU가 실제로 실행하는 대상은 실행 파일 내부에 저장된 기계어(Machine Code)입니다.

```
소스 프로그램
↓
컴파일
↓
이진 실행 파일
↓
운영체제 적재
↓
프로세스 실행
```

---

## 2. 시스템 어디에서 등장하는가

이진 실행 파일은 **컴파일 완료** 이후 **실행 시작** 이전 사이에 존재합니다.

```
소스 코드
↓
컴파일러
↓
Object File
↓
링커
↓
이진 실행 파일
↓
디스크 저장
↓
OS Loader
↓
프로세스 생성
```

즉, **빌드 시스템 → 운영체제 로더 → 프로세스 생성** 구간에서 핵심 역할을 수행합니다.

---

## 3. 어떤 자원에 가장 영향이 큰가

가장 직접적인 자원은 **Disk**와 **Memory**입니다.

| 자원 | 역할 |
|------|------|
| Disk | 실행 파일이 SSD / HDD / NVMe 위에 저장됨 |
| Memory | 실행 시 OS가 Code Segment, Data Segment 등으로 적재 |
| CPU | 메모리에 적재된 이후 기계어를 실행 |
| Network | 직접 관련 없음. 컨테이너 이미지 다운로드·원격 배포 시 간접 관련 |

---

## 4. 왜 중요한가

실행 파일은 컴파일 결과물 그 자체이며, **프로그램의 최종 형태**입니다.

실행 파일에 포함된 정보:

- 기계어 코드
- 전역 데이터
- 상수 데이터
- 심볼 정보
- 파일 헤더

실행 파일은 CPU 종류, OS 종류, ABI 규격에 맞춰 생성되므로 실행 가능 여부 자체가 결정됩니다.

예를 들어 Linux ELF 파일은 Windows에서 직접 실행되지 않습니다.

---

## 5. 실제 장애와 어떤 관련이 있는가

| 장애 유형 | 원인 | 결과 |
|-----------|------|------|
| 잘못된 CPU 아키텍처 | ARM 바이너리를 x86 서버에서 실행 | `Exec Format Error`, `Illegal Instruction` |
| ABI 불일치 | 라이브러리와 실행 파일의 ABI 상이 | Crash, Segmentation Fault, 메모리 손상 |
| 손상된 실행 파일 | 배포 중 파일 일부 손실 | 프로그램 시작 실패 |
| 잘못된 동적 라이브러리 참조 | 의존 라이브러리 누락 또는 버전 불일치 | 실행 시 로딩 실패 |

SRE 관점에서는 배포 실패, 컨테이너 시작 실패, `CrashLoopBackOff`의 원인이 되기도 합니다.

---

## 6. 핵심 메커니즘

현재 문맥에서는 다음 흐름이 핵심입니다.

```
소스 프로그램
↓
컴파일
↓
ABI 적용
↓
실행 파일 생성
```

아래 선언을 예로 들면:

```c
struct Status {
    unsigned int mode : 3;
    unsigned int flag : 1;
};
```

컴파일러는 구조체 크기, 비트 위치, 패딩 위치를 결정하고, 그 결과가 반영된 기계어와 데이터가 **실행 파일 안에 저장**됩니다.

> **핵심 사실:** 실행 파일은 설계도가 아니다.  
> 실행 파일은 이미 **ABI + ISA + 정렬 + 패딩**이 적용된 결과물이다.

## 7. Linux / Runtime / K8s에서 어디서 관측되는가

### Linux

```bash
# 파일 종류 확인
file app
# 출력 예: ELF 64-bit executable

# ELF 헤더 확인 (CPU 아키텍처, 엔트리 포인트, 파일 형식)
readelf -h app

# 섹션 확인
readelf -S app

# 심볼 확인
nm app

# 기계어 확인
objdump -d app

# 프로세스 적재 상태 확인
cat /proc/<PID>/maps
```

### Kubernetes

```
Container Image
↓
실행 파일
↓
Container Runtime
↓
프로세스
```
