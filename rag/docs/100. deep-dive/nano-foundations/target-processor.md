# 타깃 프로세서 (Target Processor)

> 정독: 0회

## 1. 이 기술이 무엇인가

타깃 프로세서(Target Processor)는:

> 컴파일된 프로그램이 최종적으로 실행될 CPU를 의미

컴파일러는 단순히 코드를 기계어로 번역하는 것이 아니라, **어떤 CPU에서 실행될 것인가**를 기준으로 기계어를 생성합니다.

```
소스 프로그램
↓
컴파일러
↓
타깃 프로세서용 기계어 생성
↓
실행
```

이 과정에서 기준이 되는 CPU가 타깃 프로세서입니다.

---

## 2. 시스템 어디에서 등장하는가

```
소스 프로그램 작성
↓
컴파일
↓
타깃 프로세서용 바이너리 생성
↓
운영체제 적재
↓
타깃 프로세서 실행
```

타깃 프로세서는 **컴파일 단계**와 **실행 단계** 두 곳 모두에 영향을 줍니다.

- 컴파일러는 타깃 프로세서를 기준으로 코드를 생성합니다.
- 실행 시에는 실제 타깃 프로세서가 그 코드를 해석합니다.

---

## 3. 어떤 자원에 가장 영향이 큰가

가장 직접적인 영향은 **CPU**와 **Memory**입니다.

| 자원 | 결정 요소 |
|------|-----------|
| CPU | ISA, 레지스터 구조, ALU 구조, 명령어 길이 |
| Memory | 엔디언, 정렬 규칙, 메모리 접근 방식, 캐시 구조 |

Network와 Disk에는 간접적으로만 영향을 줍니다.

---

## 4. 왜 중요한가

타깃 프로세서는 소프트웨어가 실제로 사용할 수 있는 하드웨어 규칙을 결정합니다.

`x86-64`, `ARM64`, `RISC-V`는 서로 다른 ISA를 사용합니다. 따라서 같은 소스 코드라도 다음이 달라집니다.

- 생성되는 기계어
- 레지스터 사용법
- 최적화 방식

또한 다음도 결정합니다.

- 비트 폭
- 엔디언
- 정렬 규칙
- 원자성 (Atomicity)

---

## 5. 실제 장애와 어떤 관련이 있는가

| 장애 유형 | 원인 | 결과 |
|-----------|------|------|
| ISA 불일치 | ARM 바이너리를 x86 CPU에서 실행 시도 | 실행 불가, Illegal Instruction |
| 정렬 문제 | Misaligned Access (프로세서별 허용 여부 상이) | 성능 저하, Bus Error, Crash |
| 엔디언 문제 | Little Endian / Big Endian CPU 간 데이터 교환 | 데이터 왜곡, 프로토콜 오류 |
| 원자성 문제 | 프로세서 비트 폭보다 큰 데이터 접근 | 경쟁 조건, 데이터 손상 |

---

## 6. 핵심 메커니즘

현재 비트 필드 문맥에서는 다음 순서가 중요합니다.

```
타깃 프로세서
↓
ABI
↓
컴파일러 동작
↓
비트 필드 레이아웃
```

아래 선언을 예로 들면:

```c
struct Status {
    unsigned int mode : 3;
    unsigned int flag : 1;
};
```

컴파일러는 타깃 프로세서의 정보를 보고 레지스터 폭, 엔디언, 정렬 규칙, ABI를 확인합니다. 그 결과 비트 위치, 패딩, 정렬이 확정됩니다.

```
비트 필드 구조
↓
컴파일러
↓
타깃 프로세서 규칙 적용
↓
물리적 레이아웃 생성
```

> **핵심 사실:** 비트 필드의 실제 메모리 배치는 언어가 아니라 **타깃 프로세서 + ABI**가 결정한다.

## 7. Linux / Runtime / K8s에서 어디서 관측되는가

### Linux

```bash
# CPU 아키텍처 확인
uname -m
# 출력 예: x86_64, aarch64, riscv64

# CPU 상세 정보 (Architecture, CPU op-mode, Byte Order 등)
lscpu

# 프로세서 정보
cat /proc/cpuinfo
```

### Kubernetes

```bash
# 컨테이너 내부 아키텍처 확인
kubectl exec -it pod -- uname -m

# 이미지 아키텍처 확인
docker inspect IMAGE
docker manifest inspect IMAGE
```

실무에서는 ARM 노드와 x86 노드가 혼합된 클러스터에서 다음 문제가 자주 발생합니다.

- `Wrong Architecture`
- `Exec Format Error`
