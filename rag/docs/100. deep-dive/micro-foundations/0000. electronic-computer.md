# Electronic Computer (전자 계산기)

## 1. 무엇인가

전자 계산기(Electronic Computer)는 **입력된 데이터를 저장**하고, 프로그램의 명령에 따라 연산을 수행하여 결과를 출력하는 전자식 정보처리 시스템이다.

전자 계산기는 하드웨어와 소프트웨어가 함께 동작하여 데이터를 처리하며, 현대의 모든 정보기술 시스템의 물리적 기반이 된다.

주요 목적은 다음과 같다.

- 데이터 입력
- 데이터 저장
- 데이터 처리
- 데이터 출력
- 프로그램 실행
- 정보 생성

전자 계산기는 프로그램을 실행하여 데이터를 처리하는 범용 정보처리 장치이다.

## 2. 시스템 어디에서 등장하는가

전자 계산기는 모든 소프트웨어가 실행되는 가장 하위의 물리적 시스템이다.

전체 구조는 다음과 같다.

```
Application
      ↓
Operating System
      ↓
Electronic Computer
      ↓
Hardware Resources
```

전자 계산기는 일반적으로 다음 구성 요소로 이루어진다.

- CPU
- Memory
- Storage
- Input Device
- Output Device
- Network Interface

프로그램 실행 흐름은 다음과 같다.

```
Input
      ↓
Memory
      ↓
CPU Processing
      ↓
Output
```

## 3. 어떤 자원(CPU/Memory/Network/Disk)에 가장 영향이 큰가

전자 계산기는 시스템의 모든 물리적 자원을 제공한다.

| 자원 | 영향 |
|---|---|
| CPU | 명령어 실행 및 연산 |
| Memory | 프로그램과 데이터 저장 |
| Network | 외부 시스템과 데이터 통신 |
| Disk | 데이터와 프로그램 저장 |

### CPU

대표 작업

- 명령어 실행
- 산술 연산
- 논리 연산
- 제어 수행

### Memory

대표 작업

- 프로그램 적재
- 데이터 저장
- 실행 중 데이터 관리

### Network

대표 작업

- 데이터 송수신
- 원격 통신
- 패킷 처리

### Disk

대표 작업

- 운영체제 저장
- 프로그램 저장
- 데이터 저장
- 로그 저장

## 4. 왜 중요한가

모든 소프트웨어는 전자 계산기 위에서 실행된다.

전자 계산기의 성능과 자원은 전체 시스템의 처리 능력을 결정한다.

다음과 같은 품질 특성에 직접적인 영향을 준다.

- 처리 성능
- 신뢰성
- 가용성
- 확장성
- 안정성

전자 계산기의 자원 한계는 애플리케이션과 운영체제의 성능 한계를 결정한다.

## 5. 실제 장애와 어떤 관련이 있는가

운영 환경에서는 전자 계산기의 물리적 자원 한계나 하드웨어 문제로 다양한 장애가 발생할 수 있다.

### CPU 관련

**원인**

- CPU 과부하
- 연산량 증가
- 프로세스 증가

**결과**

- CPU Usage 증가
- Latency 증가
- 처리량 감소

### Memory 관련

**원인**

- Memory 부족
- 메모리 오류
- 메모리 사용량 증가

**결과**

- OOM
- 프로세스 종료
- 응답시간 증가

### Network 관련

**원인**

- 네트워크 장애
- 패킷 손실
- 대역폭 부족

**결과**

- Timeout
- Connection Failure
- 서비스 지연

### Disk 관련

**원인**

- Disk I/O 증가
- 저장 공간 부족
- 디스크 장애

**결과**

- Storage Failure
- 응답시간 증가
- 서비스 중단

### 하드웨어 관련

**원인**

- 전원 장애
- 장치 고장
- 과열
- 장비 노후화

**결과**

- 시스템 중단
- 재부팅
- 데이터 손상
- 서비스 장애

## 6. 현재 문맥에서 꼭 알아야 하는 핵심 메커니즘만 설명

E2E SRE 문서를 읽는 관점에서는 전자 계산기를 다음 여섯 가지 핵심 기능으로 이해하면 충분하다.

### 입력(Input)

외부 데이터를 수신한다.

- Keyboard
- Network
- Storage
- Sensor

### 저장(Storage)

프로그램과 데이터를 저장한다.

- Memory
- Disk

### 실행(Execution)

프로그램의 명령을 수행한다.

- Instruction Fetch
- Instruction Decode
- Instruction Execute

### 연산(Processing)

데이터를 계산하고 처리한다.

- Arithmetic
- Logical Operation
- Control Operation

### 출력(Output)

처리 결과를 외부로 전달한다.

- Display
- Network
- Storage

### 자원 관리(Resource Usage)

프로그램 실행에 필요한 물리적 자원을 제공한다.

- CPU
- Memory
- Network
- Disk

### 핵심 처리 흐름

```
Input
      ↓
Memory
      ↓
CPU
      ↓
Output
```

E2E SRE 관점에서는

> 컴퓨터가 어떤 장치로 구성되는가

보다

- 프로그램이 어떻게 실행되는가
- CPU가 어떻게 명령을 수행하는가
- 메모리가 어떻게 사용되는가
- 입출력이 어떻게 수행되는가

를 이해하는 것이 중요하다.

## E2E SRE 문서 관점 핵심 정리

전자 계산기는

> 프로그램의 명령에 따라 데이터를 입력하고, 저장하고, 연산하여 결과를 출력하는 전자식 정보처리 시스템이다.

핵심 구성 요소는

- CPU
- Memory
- Storage
- Input
- Output
- Network Interface

이다.

E2E SRE 관점에서는

```
Application
      ↓
Operating System
      ↓
Electronic Computer
      ↓
CPU / Memory / Network / Disk 사용 특성
      ↓
Observability
```

의 흐름으로 이해하면 된다.

운영 환경에서 관측되는

- CPU Usage 증가
- Memory 부족
- OOM
- Disk I/O 증가
- Network Timeout
- Hardware Failure
- Node 장애

등은 대부분 전자 계산기의 물리적 자원 한계 또는 하드웨어 장애와 관련되어 발생한다.

전자 계산기의 핵심은 프로그램을 실행하기 위한 물리적 기반을 제공하고, CPU·메모리·저장장치·네트워크 자원을 이용하여 데이터를 처리하고 결과를 생성하는 것이다.
