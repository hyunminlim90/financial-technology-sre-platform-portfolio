## 1. 이 기술이 무엇인가

**SHA-256**은:

> 입력 데이터를 **256bit 고정 길이 해시값**으로 변환하는 단방향 해시 함수

SHA-2 계열 알고리즘 중 가장 대표적으로 사용된다.

### 출력 특징

- 출력 길이: `256bit = 32byte = 64자리 hexadecimal 문자열`
- 예시: `2cf24dba5fb0a30e26e83b2ac5b9e29e...`

### 핵심 특징

| 특징 | 의미 |
|------|------|
| 단방향성 | 역산 불가능 |
| 고정 길이 출력 | 입력 크기 무관 |
| Collision Resistance | 동일 해시 생성 매우 어려움 |
| Avalanche Effect | 입력 일부 변경 시 결과 완전 변경 |

## 2. 시스템 어디에서 등장하는가

SHA-256은 **핀테크 인프라 전반**에 등장한다.

### TLS / HTTPS
- Certificate Signature
- Handshake Integrity

### API Signature
- `HMAC-SHA256`
- Request Validation

### 결제 무결성 검증
- Payment Payload Integrity
- Transaction Verification

### Password Storage
직접 Password Hash로 단독 사용은 감소했지만, 아래 내부 기반으로 사용됨:
- `PBKDF2`
- `HMAC`

### Blockchain
- Bitcoin
- Ledger Integrity
- Merkle Tree

### JVM / Application
- File Checksum
- Object Integrity
- Cache Key

## 3. 어떤 자원(CPU/Memory/Network/Disk)에 가장 영향이 큰가

가장 직접 영향: **CPU**

> SHA-256은 내부적으로 대량의 `XOR`, `Rotate`, `Shift`, `Add` 연산을 반복 수행.
> 즉, **ALU + SIMD Unit 집중 사용** 구조.

### Memory 영향

상대적으로 낮은 편. 하지만 아래 상황에서 CPU Cache 영향 발생 가능:

- 대량 concurrent hashing
- TLS handshake 폭증

---

## 4. 왜 중요한가

핀테크 시스템에서 SHA-256은 **무결성과 인증의 핵심 기반**이기 때문.

### 대표 역할

| 역할 | 의미 |
|------|------|
| 데이터 위변조 방지 | Integrity |
| API 인증 | HMAC |
| TLS 보안 | Signature |
| Blockchain 검증 | Ledger Integrity |
| 파일 검증 | Checksum |

> ⚠️ SHA-256이 깨지면: **신뢰 체계 전체 붕괴 가능**

## 5. 실제 장애와 어떤 관련이 있는가

### TLS CPU Saturation
HTTPS 트래픽 폭증 시 SHA 계산 증가 → CPU 사용률 증가 발생 가능

### Handshake Bottleneck
TLS Handshake 대량 발생 시 부하 증가:
- Signature 검증
- Certificate Validation

### Retry Storm
서명 검증 실패 시 재시도 증가 → API 폭주 가능

### Tail Latency 증가
CPU Core가 SHA 연산에 장시간 점유되면:
- Event Loop Delay
- P99 증가 발생 가능

### Weak Hardware Acceleration
SHA-NI 없는 CPU 환경에서는 소프트웨어 SHA 계산 비용 증가 가능

### Crypto Hotspot
특정 Core에 암호화 인터럽트 집중 가능

## 6. 현재 문맥에서 꼭 알아야 하는 핵심 메커니즘만 설명

### Compression Function
SHA-256은 데이터를 **block 단위로 압축 반복 수행**

### Bitwise Operation
핵심 연산: `XOR`, `Rotate`, `Shift`

### Avalanche Effect
입력 일부 변경 시 출력 전체 변화

### Merkle-Damgård Structure
SHA-256 내부 구조 기반. 연속 block 처리 방식.

### SHA-NI
Intel/AMD CPU의 SHA 가속 명령어

### SIMD / Vectorization
대량 SHA 계산 최적화 가능

### HMAC-SHA256
Secret Key 기반 인증 방식. **핀테크 API에서 매우 중요.**
