철학적 관점

결국 워드 단위로 cpu 에서 산술(사칙연산=올림자리발생)·논리(AND·OR·XOR·NOT=비트별 독립연산=캐리없음) 연산처리 된다.
데이터 구조는 설계에 따라 memory 성능을 효율적으로 사용한다.
파일 구조 및 대용량 데이터 저장은 프로그래밍 기법에 따라 disk 성능을 결정한다.
하나의 시스템·컴포넌트·서비스에 대한 cpu 처리량의 부하 설계는 network 처리 한계에 의존적이다.
- cpu 외부 처리는 모두 I/O 작업이며, 어떤 시스템 인터페이스를 사용하는지에 따라 성능이 결정된다.
- 소프트웨어(High) 코드 한 줄에서부터 cpu 명령어로 처리되기까지 전 과정에 대한 내부 메커니즘을 익히는 것은 매우 흥미로운 학습 방법이다.
