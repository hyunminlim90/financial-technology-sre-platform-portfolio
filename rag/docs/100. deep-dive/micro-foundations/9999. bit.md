철학적 관점

결국 워드 단위로 cpu 에서 산술(사칙연산=올림자리발생)·논리(AND·OR·XOR·NOT=비트별 독립연산=캐리없음) 연산처리 된다.
데이터 구조는 설계에 따라 memory 성능을 효율적으로 사용한다.
파일 구조 및 대용량 데이터 저장은 프로그래밍 기법에 따라 disk 성능을 결정한다.
하나의 시스템·컴포넌트·서비스에 대한 cpu 처리량의 부하 설계는 network 처리 한계에 의존적이다.
- cpu 외부 처리는 모두 I/O 작업이며, 어떤 시스템 인터페이스를 사용하는지에 따라 성능이 결정된다.
- 소프트웨어(High) 코드 한 줄에서부터 cpu 명령어로 처리되기까지 전 과정에 대한 내부 메커니즘을 익히는 것은 매우 흥미로운 학습 방법이다.
  e.g. 비유로 자동차 핸들을 조작하는 사람의 손에서부터 끝지점인 바퀴가 좌우로 이동하는 동작 사이의 전체 메커니즘을 숙지하지 못한 자동차 정비사는
       고장 수리 시 만원짜리 부품 하나만 교체하면 되는데, 10만원짜리 부품 통째를 교체하는 웃지 못할 일이 벌어질 수 있다.

더 깊히 컴퓨터를 이해하면 집적 회로(IC)와 DRAM(T1C1)이 기본 구성 단위다.
- 집적 회로(IC)는 데이터를 처리하고 저장하는 반도체 칩 전체의 기본 형태를 의미한다.
- T1C1은 1개의 트랜지스터(Transistor)와 1개의 커패시터(Capacitor)로 이루어진 가장 효율적인 셀(Cell) 구조를 의미한다.
  DRAM과 같은 메모리 반도체에서 데이터를 저장하는 최소 단위로 커패시터에 전하를(전기 입자) 채우거나(리프레시) 방전하여  
  데이터를 '1'과 '0'으로 기억하는 메모리 반도체의 핵심 기본 단위다.
